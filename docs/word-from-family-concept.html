State addition to TakeHeartScene
// Add alongside existing verseIndex state:
const [familyIndex, setFamilyIndex] = useState(0);
const familyPaused = useRef(false);

// Separate interval — independent cycle from verses:
useEffect(() => {
  const interval = setInterval(() => {
    if (!familyPaused.current) {
      setFamilyIndex((i) => (i + 1) % FAMILY_WORDS.length);
    }
  }, 12000);
  return () => clearInterval(interval);
}, []);

const cycleFamilyWord = useCallback(() => {
  setFamilyIndex((i) => (i + 1) % FAMILY_WORDS.length);
}, []);

Design note — placement + visual logic

Placement between Word for Today and Practical Guidance is the right call. The scene follows an emotional arc: God speaks first (scripture), then the Body speaks (family words), then action (guidance + EAP). Placing the human voice immediately after the divine word lets the persecuted leader experience community as a continuation of that encounter — not as an interruption or afterthought. It would feel wrong to put human words before God's, and putting them after the practical guidance would bury them under operational content.

Open text, no card border. The Word for Today and the scripture footer are also borderless centered blocks. The Practical Guidance section introduces bordered cards as a visual register shift — "these are things to do." The family words belong in the same register as the scripture: received, sat with, not acted on. A border would add utility-object energy to what should feel like a letter.

Sky dot, not red. Red in this tab is a severity signal. Using red here would bleed threshold meaning into a warmth context and dilute both. Sky is established as the accent color for human-network elements (guidance icons, EAP button, Connect tab) — it is the right color for words that come from verified brothers and sisters in the network.

displayRegular (roman) for the body. scriptureItalic is reserved for God's word and quoted historical witness. These are contemporary human words in present tense. Roman weight at 19px reads as "a letter" — warm, present, personal — without claiming the elevated register that italic connotes in this system.

Attribution format: "A [Role] from [Region]." Role + region follows Replant's identity safety rules for this surface. The indefinite article "A" matters: it makes each attribution feel like it could be any of many pastors in that region — which is true — and prevents the reader from fixating on a specific person rather than the word itself.
