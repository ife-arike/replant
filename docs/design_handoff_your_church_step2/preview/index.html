01

"Edit" moves inline; the apologetic sub-module is gone

The standalone "Made a mistake? Select an option below." centered block is removed — its centered alignment fought the left-aligned hierarchy above it. Edit becomes a quiet text affordance in the card's ribbon, where the user is already looking when they read the confirmation.

02

The amber dot finally gets a name

A dedicated status row spells out Awaiting verification, what to expect ("2–3 days"), and that the account remains active. This is the single biggest fix — currently the dot is a mystery the user has to guess at.

03

Destructive action demoted properly

"Delete and return to search" — red, full-width, equal visual weight to Edit — was a one-tap mistake waiting to happen. It becomes a quiet "Made a mistake? Switch ›" text link below the card. The destructive confirmation lives inside the switch flow, not on this screen.

04

CTA keeps its sky, gains the serif

Sky pill stays — it's the established primary in your flow. The label switches to Cormorant 22 px so the moment of entering the network feels weightier than a system-font button.
