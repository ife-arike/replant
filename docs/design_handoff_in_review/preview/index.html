Mark as in review — one admin claims the case, and walks with the leader

A claim layer over UndergroundDetail.jsx and the Pending queue. When an admin marks a submission in review, the case is theirs to progress — and the claim locks proposal initiation to them (Founder ruling, overriding BA's lean). Others can still confirm the claimer's proposal (the two-eyes step) and can request release, but only the claimer writes narrative notes, uploads evidence, or initiates Verify / Reject / Request-info / Visibility-override / Rotate. Built entirely in the live rp-* + .state-* design system — no new tokens.
