The row, not strays

One parent row, every modifier inside

The Display-name radio, the two checkboxes, and the Honorific + Suffix pickers are not five peers in the Account section — they are one decision (how my name appears) with five controls. So they all live inside a single s-row under the Display name shown to others label, with the bordered Password row below.

  • Each radio shows its own example in italic-serif sky — the selected option in full sky, the other dimmed. So when you flip Show last name first, both labels and previews update — and you can see the shape before committing.
  • Format mono eyebrow groups the two checkboxes. Real squares — hairline outline off, sky border + sky-tint fill + sky check on — same sky language as the active radio dot.
  • Honorific + Suffix sit side by side, left-aligned. Mono label and the italic-serif sky value share a line with a small gap between them — because the page reads left-aligned, the value belongs next to its label, not stranded at the right edge.
  • Toggle the checkboxes in the After phone to watch the labels and previews update live — it's a working spec, not a static mock.

The sheets, on-brand

A sheet, not a system menu

The current Honorific sheet reads as a stock iOS picker. The fix brings both sheets (Honorific + the new Suffix) into the same register as the rest of Settings.

  • Mono eyebrow + italic-serif title. Choose one above Honorific / Suffix — the brand's numbered-section pattern compressed into a modal head, with the hairline rule under it.
  • One short line of context under the title, so the choice doesn't land cold — nothing about denomination or tradition, just what the field does.
  • Each option is an italic-serif specimen. Same face as the live name preview — the picker shows you what your name will look like, not just a list of strings.
  • Selected state uses the same ◉/○ sky glyph as the radio group above; nothing new to learn.
  • Suffix "Other…" opens a short text field so a leader can enter letters we didn't list (honorary, ThM, EdD, etc.) without us pretending to know every credential register.
